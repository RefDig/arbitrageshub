# BuilderLYs Studio – Frontend Next.js

## Pages disponibles
- `/` : Accueil
- `/auth` : Authentification
- `/automation` : Automatisation
- `/generator` : Générateur site/app
- `/marketplace` : Marketplace
- `/payment` : Paiement Stripe
- `/training` : Formation

## Connexion au backend
Les appels sont faits sur `http://localhost:3001/` (backend Express.js).
Pense à lancer le backend avant d’utiliser le frontend.

## Personnalisation
- Ajoute des hooks API pour chaque module
- Intègre la gestion du token JWT
- Améliore l’UI selon tes besoins
